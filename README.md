# Объектно-ориентированное программирование

Лабораторные работы по ООП

- **ЛР №1** — просмотр каркасной 3D-модели: загрузка, перенос, масштабирование и поворот.
- **ЛР №2** — шаблонный вектор: перегрузка операторов, итераторы, исключения и тесты на Google Test.
- **ЛР №3** — объектно-ориентированный 3D-просмотрщик со сценой, моделями, камерами и паттернами проектирования.
- **ЛР №4** — моделирование лифта на конечных автоматах с использованием сигналов, слотов и таймеров Qt.
